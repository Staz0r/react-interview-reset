A focused one-day refresh

About 2½ hours, with short breaks

You do not need to relearn all of React or JavaScript. Read briefly, write code yourself, and stop when this pass is done.

  1. 20 min
    React refresh

    Skim the counter guide and structure companion.

  2. 35 min
    Build the counter

    Use the scaffold, then restore the example and rebuild without looking. Explain state, JSX, and the click handler.

  3. 25 min
    Debug two small bugs

    Read the JavaScript guide and fix both debugging tasks in the lab.

  4. 40 min
    Practice algorithms

    Solve sum-positive, then choose count-vowels or find-a-pair. Test normal and edge cases.

  5. 15 min
    Recall and rest

    Say how you would build, debug, and test each task without reading. Then call it done.

That is about 2¼ hours of focused work plus breaks. Sleep and a calm explanation matter more than an all-nighter.
