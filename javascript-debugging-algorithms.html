Debug one thing at a time.

For a small JavaScript problem, the interviewer is watching how he reasons. He can look up syntax. He should make the input, output, and steps clear.

1. ClarifyWhat goes in? What must come back?
2. ExampleTry a normal case and an edge case by hand.
3. ImplementStart with the simplest correct steps.
4. Test aloudRun examples; trace values if one fails.

Small syntax kit

Name a value

const for a value you won't reassign; let for a changing total or loop index.

const item = items[i];

Define a function

Parameters are the inputs; return gives the answer back.

function solve(items) { ... }

Loop through an array

Indexes start at zero. Stop before the length.

for (let i = 0; i < items.length; i++)

Choose a case

if runs a block when its condition is true. Use strict equality to compare.

if (item === target) { ... }

Build an answer

Update an accumulator or add a result to an array.

total += value;   result.push(value);

Return at the right time

Return early when found; otherwise finish the loop first.

return answer;

Common bug: returning during the first loop pass

for (let i = 0; i < numbers.length; i++) { total += numbers[i]; return total; // stops after one item } return total; // put this after the loop

When a test fails

  • Read the first error line carefully.
  • Check spelling and capitalization.
  • Log the input and current value.
  • Check loop bounds and return placement.
  • Test empty, one-item, and normal inputs.
  • Fix the smallest cause, then rerun all tests.

Google is useful for syntax and error messages. Search for the exact construct, prefer MDN, then explain and adapt it yourself. Avoid relying on a copied solution you can't walk through.

Three small problems to rehearse

Do them in order. Try each before opening the interactive lab's hint or sample solution.

1. Sum the positive numbers

Write sumPositive(numbers). Return the sum of values greater than zero. If none are positive, return zero.

sumPositive([3, -2, 5]) → 8
sumPositive([]) → 0
sumPositive([-4, 0]) → 0

Think: start a total at 0; loop; add only when a value is positive; return after the loop.

2. Count vowels

Write countVowels(text). Count a, e, i, o, u regardless of case. An empty string returns zero.

countVowels("React") → 2
countVowels("WHY") → 0
countVowels("") → 0

Think: normalize case once, visit each character, and increase a count when it is a vowel.

3. Find a pair that adds to a target

Write twoSum(numbers, target). Return the indexes of two different items that add to target. Return [] if no pair exists.

twoSum([2, 7, 11, 15], 9) → [0, 1]
twoSum([3, 3], 6) → [0, 1]
twoSum([1, 2], 8) → []

Think: compare each pair with two loops; start the second index at the first index plus one. A simple correct solution is a good start.

Say what you're doing

“I’ll confirm the return format, try a small example, then write a direct solution. I’ll test the empty and boundary cases. If it fails, I’ll trace the loop index and current value.”

One focused round of these patterns is more useful than trying to memorize a long list of algorithms the night before.
