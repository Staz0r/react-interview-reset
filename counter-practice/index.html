1Guard zeroWarm-up

Hint

2Add a +5 buttonEasy

Add one button that increases the count by five.

Hint

3Show even or oddSyntax

Under the count, show whether it is even or odd.

Hint

Use a ternary expression: count % 2 === 0 ? "Even" : "Odd".

4Disable at zeroStretch

Hint

Quick knowledge check

Which form passes the handler?
onClick={handleClick} or onClick={handleClick()}?
Pass it: onClick={handleClick}. With parentheses, it runs during render.

JavaScript syntax decoder

const [count, setCount] = ...

Destructuring gives two names: the current value and the function that updates it.

current => current + 1

An arrow function receives current and returns the next value.

{count}

JSX braces mean: evaluate this JavaScript expression and show its value.

handleClick vs handleClick()

The first is the function. Parentheses call it now.

= vs ===

One equals assigns. Three equals compare.

Math.max(0, current - 1)

Calculate the next count, but never let it go below zero.

disabled={count === 0}

JSX evaluates the comparison. When it is true, the button is disabled.

count % 2 === 0 ? "Even" : "Odd"

The remainder operator checks parity; the ternary chooses one of two labels.

Micro-drill: What does current => current - 1 do?
It is a function that takes the current count and returns one less.
