Where does React code go?

In a React project, you usually describe the interface with components and JSX. React mounts that component tree into one HTML element, then manages the app UI for you.

1. index.htmlHas an empty mount point: <div id="root"></div>
->
2. src/main.jsxFinds that element once and tells React to render <App />.
->
3. src/App.jsxDescribes the UI with components, state, events, and JSX.
Does a React developer need to use the DOM?

React uses the browser DOM to show the interface, but you normally do not edit DOM nodes yourself. Write JSX and update state; React updates the DOM. The one DOM lookup in a simple client app is usually in the entry file when it connects React to #root.

A typical small project shape

HTML shell

index.html
Contains <div id="root"></div> and loads the app entry file.

Entry point

src/main.jsx
Imports the app and calls createRoot(...).render(<App />) once.

App component

src/App.jsx
The top-level UI. It can contain a counter directly or use smaller components.

Optional pieces

src/Counter.jsx and src/App.css
Split UI or styling into files when that makes the app easier to read.

What the entry file does

import { createRoot } from 'react-dom/client';
import App from './App.jsx';
import './index.css';

const rootElement = document.getElementById('root');
createRoot(rootElement).render(<App />);

That is the setup step. In an interview, the starter project may already do it for you. Check its files and continue in the existing component; filenames vary by tool and framework.

JavaScript syntax in a counter

Read the line in plain words. You do not have to memorize every symbol if you can recognize the pattern and look up the detail.

State destructuring

React gives a current value and a setter. The brackets name both returned items.

const [count, setCount] = useState(0)

Named function

Defines a set of instructions to run later. Parentheses after the name call it now.

function handleClick() { ... }

Arrow function

A compact function. Here it receives the old count and returns the next one.

current => current + 1

JSX braces

Inside JSX, braces mean evaluate this JavaScript and show its value.

<p>{count}</p>

Pass vs. call

Pass a handler to run after the click; do not call it while rendering.

onClick={handleClick}

Assign vs. compare

One equals assigns. Three equals compare.

count = 0   count === 0

Put the patterns together

import { useState } from 'react';

export default function App() {
  const [count, setCount] = useState(0);

  function handleIncrease() {
    setCount(current => current + 1);
  }

  return (
    <main>
      <p>Count: {count}</p>
      <button onClick={handleIncrease}>Add one</button>
    </main>
  );
}
Say it without jargon
  1. What two things are named by [count, setCount]?
  2. What does current => current + 1 return?
  3. Why is the handler passed as onClick={handleIncrease}?

Answers: the current value and its setter; the next count; React should call the function after a click.
