# Interview Reset: React + JavaScript

A mobile-friendly static site with printable interview refresh guides and browser-based practice labs.

## Contents

- `index.html`: landing page
- `quick-react-reset.html`: React counter interview guide
- `react-structure-and-syntax.html`: React structure and JavaScript syntax companion
- `javascript-debugging-algorithms.html`: debugging and algorithm quick guide
- `javascript-practice-lab.html`: standalone JavaScript practice lab
- `counter-practice/`: React counter playground
- `downloads/`: downloadable practice bundles

## Publish with GitHub Pages

1. Create a public GitHub repository and upload/push the contents of this folder to its root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for the Pages deployment to finish. The site URL appears on the Pages settings screen.

The JavaScript lab runs without external libraries. The React counter playground loads React and Babel from a CDN, so it needs an internet connection.
