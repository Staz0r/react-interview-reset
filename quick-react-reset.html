Interview Reset01 - Read the JavaScript

Syntax decoder: only what the counter uses

Treat these as patterns to recognize, not a list to memorize. Read the symbol, say what it does, then keep going.

const

Creates a named binding. Use it for values you do not reassign.

const start = 0;

Array destructuring

Pulls the two returned items into names: current value, then setter.

const [count, setCount] = useState(0)

Function

Defines work to run later. Parentheses call it now.

function handleClick() { ... }

Arrow function

A compact function. This one receives current and returns the next value.

current => current + 1

JSX braces

Inside JSX, braces let you use a JavaScript value or expression.

<p>{count}</p>

Equals signs

One equals assigns a value. Three equals compare values.

count = 0 / count === 0

The easy-to-mix-up part

function handleIncrease() { setCount(current => current + 1); } <button onClick={handleIncrease}>Add one</button>
Read it out loud: Define a function. When the button is clicked, React calls it. The setter receives a function that calculates the next count from the current count.

Pass the function

onClick={handleIncrease} means "run this after a click."

Do not call it during render

onClick={handleIncrease()} runs it immediately while React is rendering.

If a symbol blanks, search the exact phrase: JavaScript arrow function array destructuring React onClick pass function. Prefer MDN or react.dev, then explain the line in your own words.

Interview Reset02 - Understand React

The four pieces you need

Component

A JavaScript function with a capitalized name that returns JSX.

function Counter() { ... }

JSX

Markup-like syntax inside JavaScript. Use braces to put a JS value into the UI.

<output>{count}</output>

State

A component's changing memory. Updating it asks React to render again.

const [count, setCount] = useState(0)

Event handler

A function passed to a UI event such as a button click.

onClick={handleIncrement}

A small component shape

import { useState } from 'react'; function Counter() { const [count, setCount] = useState(0); return ( <main> <h1>Counter</h1> <p>{count}</p> <button onClick={() => setCount(c => c + 1)}> Add one </button> </main> ); }
Read this in plain English: Start count at zero. Show it. When the button is clicked, calculate the next count. React updates the screen.

Remember these small rules

Component names start uppercaseCall hooks at the top levelUse {count} to show a valuePass a handler; do not call it

Interview Reset03 - Counter reference

Complete example: count up, down, reset

Read it once, then rebuild it from memory. The updater form current => current + 1 makes it clear that the next value comes from the previous value.

import { useState } from 'react'; export default function Counter() { const [count, setCount] = useState(0); function handleIncrease() { setCount(current => current + 1); } function handleDecrease() { setCount(current => current - 1); } function handleReset() { setCount(0); } return ( <main> <h1>Counter</h1> <p aria-live="polite">Count: {count}</p> <button onClick={handleDecrease}>Decrease</button> <button onClick={handleReset}>Reset</button> <button onClick={handleIncrease}>Increase</button> </main> ); }

Build it in this order

  1. Write a Counter component that returns a heading and a button.
  2. Add useState(0). Render count between the heading and button.
  3. Pass a click handler to the button. Use the setter to increase the count.
  4. Add decrease and reset. Test each button; narrate what state changes.

If the prompt says "never below zero"

Use setCount(current => Math.max(0, current - 1)), or disable Decrease when count === 0.

If the prompt stays simple

Do not add features before the basic counter works. Get the requested behavior working, then ask whether they'd like an edge case.

For the state setter and updater function, see the official React useState reference.

Interview Reset04 - Interview rhythm

When you get the prompt

  1. Clarify. "Should the count start at zero? Can it go below zero? Do you want reset?"
  2. Plan. "I'll keep the number in state and use click handlers to update it."
  3. Build the smallest version. Show the count and make one button work first.
  4. Test aloud. Click increase, decrease, reset. Check the starting value and any stated boundary.
  5. Polish if time allows. Use clear names and native buttons. Explain any tradeoff.

Common slips to catch

SlipQuick correction
Changing a normal variableUse the state setter so React knows to render again.
onClick={handleClick()}Pass the function: onClick={handleClick}.
Displaying text but not the valueUse braces in JSX: <p>{count}</p>.
Hook inside a condition or handlerCall useState at the top level of the component.
Trying to do everything at onceGet one behavior working, then add the next.
